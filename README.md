# Real-Estate-Similarity-Finder
Machine Learning project using K-Nearest Neighbors (KNN) to predict real estate values. Includes data preprocessing, missing-value handling, duplicate removal, feature scaling, exploratory data analysis, and model evaluation using MAE, MSE, RMSE, and R² Score.

1. Developed a Real Estate Similarity Finder using the K-Nearest Neighbors (KNN) Regressor algorithm.
2. Used a dataset containing 6,511 real-estate property records with 18 features for analysis and prediction.
3. Performed data cleaning and preprocessing to improve the quality and consistency of the dataset.
4. Handled missing values and duplicate records before building the machine learning model.
5. Renamed and organized columns to make the dataset easier to understand and analyze.
6. Conducted Exploratory Data Analysis (EDA) using Pandas, Matplotlib, and Seaborn to identify patterns and relationships in the data.
7. Applied StandardScaler to scale numerical features and ensure that different feature ranges did not negatively affect the KNN model.
8. Divided the dataset into training and testing sets to train the model and evaluate its performance on unseen data.
9. Trained a KNN Regressor to predict median house values, using similarities between property records.
10. Evaluated the model using MAE, MSE, RMSE, and R² Score to measure prediction accuracy and overall model performance.
