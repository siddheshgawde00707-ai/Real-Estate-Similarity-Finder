# Real-Estate-Similarity-Finder
Machine Learning project using K-Nearest Neighbors (KNN) to predict real estate values. Includes data preprocessing, missing-value handling, duplicate removal, feature scaling, exploratory data analysis, and model evaluation using MAE, MSE, RMSE, and R² Score.

1. Built a real estate prediction model using K-Nearest Neighbors (KNN).
2. Used a dataset containing 6,511 property records and 18 features.
3. Performed data cleaning and preprocessing.
4. Handled missing values in the dataset.
5. Renamed columns for better readability and understanding.
6. Performed exploratory data analysis using Pandas, Matplotlib, and Seaborn.
7. Used StandardScaler for feature scaling.
8. Split the data into training and testing sets.
9. Trained a KNN Regressor to predict median house values.
10. Evaluated model performance using MAE, MSE, RMSE, and R² Score.
